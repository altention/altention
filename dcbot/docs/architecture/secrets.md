# 秘密和遮蔽

從 `dcbot/CLAUDE.md` 的「架構」搬來，原文沒改（2026-11-19）。路徑相對於 `dcbot/`；接頭指 `altention/connectors/claude_code/`。

- **秘密不給任何 agent 讀**（K-03）：清單在 `altention/secrets.py`（預設：`~/.config/altention/secrets/**`、`~/.config/dcbot/**`、`~/.ssh/id_*`、`~/.ssh/*key*`，`.pub` 和 `authorized_keys` 不算；實例 `core.secret_paths` 可以加）。守門是 `dchook --guard`，登記在每台的全域 hooks（`altention/core.plugin.json`）和機器人開的對話的 `--settings`（接頭 `hooks.hooks()`），每個工具呼叫前都跑：Read／Edit／Write／Notebook 的路徑、Grep／Glob／LS 要找的資料夾（含有秘密的，例如 `~/.config`，但不含家目錄本身）、Bash 指令裡寫出的路徑，在清單裡就回 deny（寫被擋的路徑和「需要的話請問使用者」；不寫怎麼關，那是給人看的，在 SECURITY／README，主管 10/14）。不連網路、不起別的行程，量到約 35 毫秒（直譯器啟動）。它自己出錯絕不擋一般工具：設定讀不到只用預設清單、其他錯一律放行，各記一行到 `~/.local/state/altention/secrets-guard.log`（一小時最多一行）。機器人開的對話另外有 Claude Code 自己的 deny 規則（`secrets.deny_rules()`，從同一份清單產生；需要「但不含 .pub」的那幾個只靠守門）。`core.secret_guard: false` 整個關掉。指令比對（`secrets.mentions()`，K-03a 修正版）先拆成指令和字、去引號、把 `$HOME`／`${HOME}`／`~`／`~<自己>` 換成家目錄、收掉 `//`、`/./`，萬用字元和大括號照 shell 的意思比（檔案和清單都比），上層資料夾（家目錄之內、不是家目錄本身）交給會讀進資料夾的指令（grep -r、rg、find、tar、zip、rsync、cp -r、ls -R）才算；macOS 一律不分大小寫。相對路徑照這次工具呼叫的 cwd 解開（事件的 `cwd`）。ssh／scp／sftp 的 `-i` 參數、ssh-add 載入的鑰匙、`ssh-keygen -y -f` 的參數是「用」鑰匙，放行（主管 10/14），同一行其他地方照擋。擋不到（已知限制）：指令裡 cd 之後用相對路徑、以整個家目錄為範圍的搜尋、執行時才拼出的路徑、另寫程式去開檔；更強的保護（另一個系統使用者、token 不落地）排在階段 6。
- **貼出去的字先遮金鑰**（B-12）：機器人貼到 Discord 的 Claude 的話和工具輸出（回覆、中途的話、📋 和它的展開／溢出檔、/attach、!resume、--history 的紀錄和摘要、子代理串、別的對話傳來的、終端機輸入、處理中那幾行、`/btw` 的回答）都先過 `bot/masking.py`（用 `altention/redact.py` 同一套樣式，chatlog 也用它），有遮掉就在那則最後加一行 `messages.note("masked")`。機器人自己截短的字（`…（還有 N 字`）前面若是金鑰的開頭也遮；私鑰沒有結尾那行就遮到底（已知：會連後面的 ``` 一起遮掉，只多遮不漏）。截短處的金鑰開頭要是獨立的字才算。雜湊、UUID、ID 不遮（tests/test_masking.py）。新增貼出 Claude 文字的地方要經過它。**畫面也遮**（C-127，2026-11-03）：貼窗格畫面的地方都先 `masking.screen()`（整段先遮再截，回傳遮好的字和那行小字；金鑰被窗格寬度或對話框折到下一行時：寫滿畫面寬（最寬那一列的寬度）、行尾是一段金鑰字元的列，跟下一列開頭（框線和空白之後）那段接起來再用同一套樣式找，找到就兩邊一起遮；下一列整列都是這種字元而且一樣寬時再往下接，空行停。折在金鑰的第幾個字都一樣）：`tmux_bridge.fence()`（啟動失敗、slash 指令的畫面、可能沒送進去、`/btw` 逾時、`!key`）、`screens.fenced()`（`/screen` 的文字版、📝）、`menus.body()`／`menus.cut()`（對話框、面板、標題、按鈕、按了什麼）、`screens.post()`（截圖：畫面上有金鑰就用遮好的純文字畫，不上色，因為顏色碼夾在金鑰中間時樣式看不到後半段；留給 📝 的文字也是遮好的）、`terminal.body()`／`full_output()`（shell 輸出和完整輸出檔）、`startup_ask`（啟動前的問題、按鈕）。新增貼畫面的地方要走這幾個之一（tests/test_screen_masking.py 每條路一個假金鑰）。
