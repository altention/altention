# Shared knowledge

Every Claude Code conversation, on every machine and in every Discord channel, reads the same notes. Write here what
stays true for a long time and cannot be seen in the code: your preferences and decisions, how your systems fit
together, pitfalls you hit. The sync job commits and pushes this folder.

Suggested files (create them as you need them):

- `user.md`: who you are, how you like to work and be answered.
- `systems.md`: your automations: what runs where, where its state lives.
- `gotchas.md`: machine quirks and command traps.

Machine facts belong in `../machines.json` only; do not copy them here.
