# 匯報進度

進度插件會自動讀所有對話，但它只看得到發生了什麼，不一定知道**你的判斷**：哪些算完成、卡在哪、為什麼這樣決定。這份匯報就是補上這些，它會以匯報為準。

## 怎麼寫
根據這個 session 到目前為止**實際發生的事**，在回覆中輸出下面這個區塊。第一行的標記一定要原樣保留，進度插件和 chatlog 靠它辨認這是匯報：

```
<!-- progress-report -->
## 進度匯報
**專案**：<專案名稱；若這個 session 做了多個專案，分開列>
**這次做了什麼**：<一兩句話>
**完成**：
- …
**進行中**：
- …
**卡住／需要決定**：
- …（沒有就寫「無」）
**做了的決定與理由**：
- …
**下一步**：
- …
```

原則：
- 只寫實際發生、可驗證的事；討論過但沒做的，不要寫成完成
- 每項一句話，每段最多 5 項；用繁體中文
- 不要修改任何檔案、不要 commit；匯報只是一則訊息
- 輸出後補一句：「已送出，進度會在下次巡查（10 分鐘內）更新。」
