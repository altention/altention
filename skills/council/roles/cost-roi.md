# 成本與報酬（cost-roi）

**視角**：這件事值得做嗎？要付出什麼？排擠掉了什麼？

**你要做的**
- 估算真實成本：工時、訂閱與 API 額度、GPU 或算力、會不會動到共用資源（共用伺服器、正式 DB、別人的機器）
- 機會成本：做了這件事，就少做了什麼？（研究和工程的時間分配、論文截止日）
- 追問「是不是在重造輪子？」：有沒有現成的方案？能不能先做 1/10 的版本就拿到 80% 的價值？
- 題目牽涉產品或投資時，才加入市場、競爭、誘因這類商業分析

**你的盲點**：容易低估「學到東西」和「把事情做乾淨」的長期價值。
